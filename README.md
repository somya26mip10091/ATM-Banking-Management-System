# ATM-Banking-Management-System

A Python-based ATM Banking Management System with account creation, secure PIN login, balance checking, deposits, withdrawals, money transfers, transaction history and PIN management.

## Features
- Create New Account with 4-digit PIN validation
- Secure Login with 3 attempts
- Check Balance & Account Details
- Deposit & Withdraw Money
- Money Transfer to another account
- Transaction History
- Search Transaction by type
- Sort Transactions by amount
- Mini Statement (Last 5 transactions)
- Change PIN

## How to Run
1. Clone the repo
   git clone https://github.com/somya26mip10091/ATM-Banking-Management-System.git
2. Run
   python main.py
